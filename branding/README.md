# Tools identity

The smiling pink beetroot keeps the approved illustrated style of the
btravstack family, with green leaves and soft shading; its silver open-end wrench
has a straight handle and distinct jaws, and identifies the shared build and
release toolchain. Its hands float independently of its body, without arms. Use `logo-light.svg` on light
surfaces, `logo-dark.svg` on dark surfaces, and `logo-mono.svg` for grayscale
print. `social-card.png` is the 1200 × 630 repository preview asset.

Canonical SVG source: [generate-brand.mjs](https://github.com/btravstack/btravstack.github.io/blob/main/scripts/generate-brand.mjs).
Social source: [social-card.html](https://github.com/btravstack/btravstack.github.io/blob/main/branding/social-card.html), with `?project=tools`.
These are committed local copies; displaying them requires no external service.
